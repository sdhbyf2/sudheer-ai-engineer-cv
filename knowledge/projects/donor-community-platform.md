## Overview
A full-stack donor and community engagement web application connecting contributors with charitable initiatives, featuring real-time messaging, activity feeds, donor dashboards, and automated contribution logging.

## Problem & Challenge
Non-profit organizations face high drop-off rates when relying on disjointed social channels and external payment forms that lack transparent community feedback and real-time donor interaction.

## Technical Architecture & Implementation
- **FastAPI Asynchronous Backend**: Architected Python FastAPI backend services with asynchronous SQLAlchemy database sessions, JWT authentication, and bcrypt password hashing.
- **Modern TypeScript Frontend**: Built a responsive, component-driven client in React 18 and Vite with feature-based modularity (`auth`, `chat`, `comments`, `donors`, `posts`).
- **Real-Time Communication**: Implemented WebSocket channels for live donor activity updates and interactive community messaging threads.
- **Automated Testing Suite**: Enforced test coverage across client components using Vitest.

## Engineering Outcomes
- Unified community discussion and contribution tracking into a single responsive portal.
- Reliable asynchronous API architecture capable of sustaining spikes during fundraising campaigns.
