## Overview
Developed full-stack and distributed backend functionality for GetMyHotels, an AI-powered hotel booking platform supporting customer-facing search, real-time availability, and reservation workflows.

## Problem & Challenge
Hotel search and booking workflows require fast availability lookups, real-time price and inventory updates across concurrent users, reliable asynchronous event processing, and secure payment settlement.

## Technical Architecture & Implementation
- **Event-Driven Messaging & Caching**: Worked with Kafka-driven messaging for asynchronous booking events, Redis caching for rapid search and availability lookups, and WebSockets for real-time application communication.
- **Booking & Payment Workflows**: Developed customer-facing search and reservation workflows and integrated payment gateway functionality with supporting backend services.
- **Infrastructure as Code**: Supported cloud infrastructure provisioning and environment deployment using Terraform.

## Engineering Outcomes
- Responsive, low-latency hotel search and booking experience powered by Redis caching and WebSockets.
- Resilient event-driven reservation pipeline provisioned with Terraform and Kafka.
